# Χτες ήταν μια τρελή μέρα! 😵

Небольшая игра-визуальная новелла для практики греческого (A2–B1).
Игрок проживает «сумасшедший день», делает выборы, а в конце пересказывает свой день устно, опираясь на таймлайн.

- `content.js`: все тексты, очки, условия и концовки (править здесь)
- `game.js`: движок
- `style.css`: оформление
- `audio/`: фоновые звуки (пока заглушки)

Управление: мышь или клавиши 1–4 / A, B, Enter (дальше), R (бросить кубик).

**После правок** поднимите номер `?v=…` у трёх файлов в `index.html`, иначе браузеры учеников покажут старую версию из кэша.
Публикация: `git add -A && git commit -m "…" && git push`. Сайт обновится примерно через минуту.
